# Python Project - Task 2: Password Generator

## Description
A secure password generation tool built in Python. It prompts the user for a desired password length and complexity level (basic letters/numbers vs. secure letters, numbers, and symbols) to generate random, secure passwords.

## Technologies Used
- Python 3.x (`random` and `string` modules)

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the folder containing the script.
3. Run the program using the command:
   ```bash
   python password_generator.py
