# Python Project - Task 1: Calculator

## Description
A simple, interactive console-based calculator built using Python. It allows users to perform basic arithmetic operations including addition, subtraction, multiplication, and division with built-in error handling for division by zero.

## Technologies Used
- Python 3.x

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the folder containing the script.
3. Run the program using the command:
