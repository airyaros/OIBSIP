# Python Project - Task 3: Number Guessing Game

## Description
An interactive console-based number guessing game built in Python. The computer randomly selects a number between 1 and 100, and the user attempts to guess it within a limited number of attempts, receiving higher/lower feedback hints along the way.

## Technologies Used
- Python 3.x (`random` module)

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the folder containing the script.
3. Run the program using the command:
   ```bash
   python guessing_game.py
